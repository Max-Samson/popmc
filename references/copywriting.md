# 文案规范与模板池

## 结构

```
[风味钩子 ≤ 8 字]。[情绪落点 ≤ 8 字]。
```

两句，句号收尾，总长 ≤ 18 字。感叹号最多 1 个。

## 钩子阶梯（`draw.py` 里已实现，改文案时按此优先级）

1. **风味标签**：`tags` 中同时满足 ① 不在 `STOP_TAGS` ② 长度 ≥4 ③ 含 `FLAVOR_MARKS` 里任一字。
   例：`韩式辣椒黄油风味`、`浓郁奶香拉丝芝士`、`100%纯牛肉`。
2. **名称意象**：`NAME_HOOKS` 表（鳕鱼→鱼的温柔；脆→咔嚓一声；芝士→能拉丝…）。
3. **系列氛围**：`SERIES_FALLBACK`（BU→扎实的牛肉；CH→咔嚓一声；SW→甜一下；CF→咖啡因到位…）。
4. **通用兜底**：`扎实的一口` / `刚好来一口`。

`STOP_TAGS` 里是**运营标记与品类词**（上新、爆款、人气、冰淇淋、派、蘸酱…）。
它们不能当钩子——否则会出现「上新。这批里有它。」这种机器味文案。

## 五档语气（由情绪决定）

| tone | 触发情绪 | 特征 |
|---|---|---|
| `neutral` | 随缘 / 未识别 | 克制，不硬造情绪 |
| `soft` | 疲惫、想甜 | 轻、短、不追问 |
| `up` | 开心、庆祝 | 上扬，允许一个小反转 |
| `short` | 想刺激 | 短促，动词多 |
| `dry` | 需要咖啡因 | 冷静、幽默、带自嘲 |

## 模板池（每档每稀有度 2 条，按 hash 稳定选取）

完整表在 `scripts/draw.py` 的 `TEMPLATES`。新增时遵循：**同一条不得同时适用于两个稀有度**，
否则稀有度的情绪差就消失了。

## 禁忌词（硬过滤，命中即回落安全模板）

| 类别 | 词 |
|---|---|
| 健康功效 | 养生、减肥、健康、排毒、吃了不胖 |
| 绝对化 | 最、第一、天花板、零差评 |
| 品牌关系 | 官方、联名、限量、典藏、正版授权 |
| 诱导消费 | 必买、不亏、最后一天、手慢无 |
| 赌博化 | 欧皇、非酋、氪金、血赚 |
| 对比 | 吊打、碾压、比 XX 好吃 |

实现位置：`draw.py` 的 `FORBIDDEN` 元组 + `flavor_text()` 的回落逻辑。
新增禁忌词只需改这一个元组，测试 `TestCopySafety` 会自动覆盖。

## 稀有度文案示例（真实商品，可直接用）

| 等级 | 商品 | 文案 |
|---|---|---|
| N | 麦香鱼 | 鳕鱼的软。今天想吃点温柔的。 |
| R | 板烧鸡腿堡 | 板烧滋滋。这一口，稳的。 |
| SR | 龙焰鸡腿堡 | 韩式辣椒黄油风味。赶上了，就是你的。 |
| SSR | 巨无霸 | 100%纯牛肉。传说就该这样出场。 |

## 图腾款专属 copy

写在 `series.json` 的 `pinned[].copy`，语气比模板更重，**一系列只允许一句**，避免通胀。
