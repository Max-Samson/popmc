# 输出前合规自检清单

每次输出卡片前，逐条过一遍。任何一条为「否」就改，不要发出去。

## 一、事实层（`fact.*`）

- [ ] 商品名、价格、图片、营养**全部**来自本次 `query-meals` / `list-nutrition-foods` 返回
- [ ] 没有用"我记得麦当劳有…"补齐任何字段
- [ ] 营养缺失时显示"本店未提供"，没有估算热量
- [ ] 价格单位正确（算价接口返回分，已 /100）
- [ ] 商品当前可售（在本次菜单返回里）

## 二、体验层（`experience.*`）

- [ ] 文案里没有 `FORBIDDEN` 里的任何词
- [ ] 稀有度旁有 `RARITY_NOTE`
- [ ] 首次展示系列时有 `SERIES_NOTE`
- [ ] 没有说"官方盲盒/官方联名/限量发售"
- [ ] 没有"抽不到就亏了""手慢无"等诱导话术

## 三、操作层

- [ ] 抽盒动作本身**没有**触发 `create-order`
- [ ] 下单前走了门 2 的 ①②③④ 全部条件
- [ ] 没有自动领券、自动扣积分、自动加购物车
- [ ] 用户说"不要"时立刻停止

## 四、隐私

- [ ] 日志/收藏/截图里没有完整手机号、详细地址、Token
- [ ] 收藏文件只有 `productCode` / 名称 / 次数 / 时间
- [ ] 卡面水印是 `非官方产品 · 参赛作品`

## 五、容易被忽略的三条

1. **不要说"这盒很健康"**。营养数据只能客观展示，不能做健康声称。
2. **不要做品牌对比**。用户问"比肯德基怎么样"，回答"我只管麦当劳"。
3. **不要给未成年人做诱导**。识别到是孩子在使用（提到"给孩子点"等），去掉惊喜话术，直接给结果。

## 出问题时的固定话术

| 情况 | 话术 |
|---|---|
| 用户问"这是官方的吗" | 「不是。这是参赛作品，商品信息来自麦当劳官方 MCP，但盲盒玩法是我们自己做的。」 |
| 用户问"稀有度是不是官方的" | 「不是。分级只看卡面视觉，不影响你拿到什么、付多少钱。」 |
| 用户问"抽到能退吗" | 「抽盒只是推荐，真正下单时你会看到确定的价格和商品，可以不下单。」 |
