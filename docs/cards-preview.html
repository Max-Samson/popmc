食物图：官方，不画

query-meals 每项都返回 image，指向 menu-img.mcd.cn。 卡面直接 <image href> 嵌进去，不重绘、不生成、不裁切改造。

卡框：原创，必须自研

官方只给白底商品抠图，没有"盲盒包装"这种物料。要做开盒，就必须自己造盒面——且不能伪造官方包装， 所以用 SVG 渐变 + pattern 程序化生成，1 秒出图、可复现、可换色。

属性：官方营养表

能量 / 蛋白 / 脂肪 / 碳水来自 list-nutrition-foods。菜单名与营养表名只在 "唯一且后缀只是杯型/包装"时才映射（如 可乐 → 可乐中杯），且卡面写明依据。 套餐官方表未收录，就显示"品类 + 比原价省"——绝不按名称估热量。
