# 麦盒 McBox · 内容与卡面设计规范（CONTENT-SPEC）

> 本文件定义"盲盒里到底装什么、叫什么、写什么、长什么样"。
> 内容全部由**官方数据 + 规则引擎**生成，不做人工逐条编造——这是能持续运营、也不容易出错的前提。

## 1. 系列矩阵（S1 赛季）

系列 = 泡泡玛特的"一个系列"，在麦盒里等于"菜单的一个心智桶"。骨架取自 `query-meals` 的真实分类名（已归一化）。

| 系列 | code | 主色 | 取材分类 | 定位 | 为何成立 |
|---|---|---|---|---|---|
| **牛堡宇宙** | BU | 深红 `#8B1E2D` + 金 `#F2C14E` | `巨无霸牛鱼肉堡`、`安格斯MAX厚牛堡` | 门面担当，图腾在巨无霸 | 麦当劳最经典的符号资产，识别度最高 |
| **脆鸡江湖** | CH | 橙红 `#D2461F` + 焦糖 `#F5A623` | `炸鸡`、`蘸酱炸鸡`、`鸡肉汉堡/卷` | 高频、重口、易上瘾 | SKU 最多，抽不到重复的概率最高 |
| **甜品星球** | SW | 藕粉 `#F7A8B8` + 奶白 `#FFF4E6` | `小食甜品/其他` 中的冰淇淋/派/麦旋风 | 低客单、强情绪 | 圆筒 5 元也能抽，门槛低、惊喜密度高 |
| **麦咖啡星系** | CF | 深褐 `#3E2723` + 燕麦 `#C8A97E` | `麦咖啡™` | 打工人的"续命"叙事 | 早/下午时段池天然独立 |
| **随心搭子** | CL | 薄荷 `#1E8E7E` + 米白 | `随心配1+1`、`大堡口福单人餐`、`500大卡套餐` | 预算敏感人群入口 | 直接对撞"省钱"类竞品，但用玩法包装 |
| **分享派对** | PT | 紫 `#5B4B8A` + 亮黄 | `小食拼盘/多人餐`、`开心乐园` | 多人场景 | 天然适合"端盒"（一桌一盒） |
| **晨光早餐**（时令） | AM | 晨蓝 `#2E6FA7` + 蛋黄 | 早餐时段菜单（麦满分族） | 时段限定 | 05:00-10:30 自动上架，过期自动下架 |

**时令规则**：系列带 `availableWindow: ["05:00","10:30"]`。`晨光早餐` 仅在该窗口上架；`麦咖啡星系` 全天；其余全天。
系列不可用时**不出现在选择列表**；若用户点名要它，回复"只到 10:30，现在给你换一个？"并列出当前可用的系列，不做"售罄"这种负向表达。

## 2. 稀有度与卡的"人设"

| 等级 | 名称 | 判定（规则，非人工） | 语气 | 卡片视觉 |
|---|---|---|---|---|
| N | 常驻 | 默认 | 日常、可靠、"今天也不错" | 无边框，哑光 |
| R | 人气 | tags 含 `爆款/人气/经典`，或折扣比 ≥1.4 | 夸奖、"你选对了" | 银边 + 细高光 |
| SR | 当期 | tags 含 `上新` | 稀缺、"赶上了" | 金边 + 流光扫过 |
| SSR | 图腾 | 系列 `pinned`（每系列 1 个，如 BU 的巨无霸） | 史诗、"这是传说" | 虹彩 + 粒子 + 全屏揭晓 |

> **设计要点**：稀有度只改变**视觉与文案**，不改变商品、价格、份量。这一条既是产品诚实性，也是合规底线——用户不会因为"抽到 SSR"多付钱，也不会因为"抽到 N"少拿到东西。

## 3. 编号规则

`{seriesCode}-{seq:02d}/{total:02d}`

- `total` = 该系列当期池容量
- `seq` = 池内排序序号，排序键：`price desc, productCode asc`（稳定，菜单不变则编号不变）
- 例：`CH-07/14` = 脆鸡江湖第 7 张，共 14 张

编号的意义：让"我抽到 CH-07"变成一句可传播的话。没有编号的收藏没有记忆。

## 4. 卡面文案规范（`flavorText`）

### 4.1 结构

```
[风味钩子 ≤ 8 字]。[情绪落点 ≤ 8 字]。
```

总长 ≤ 18 字（中文），两个短句，句号收尾。禁止感叹号堆叠（最多 1 个标点表达强度）。

### 4.2 生成方式（模板 + 数据槽位，非 LLM 自由发挥）

槽位来源优先级（四级阶梯，逐级回落）：

1. `tags` 中的**风味描述**（如 `韩式辣椒黄油风味`、`浓郁奶香拉丝芝士`、`100%纯牛肉`）
   —— 只取含「风味/香/脆/浓/辣/甜/奶/芝士…」等风味词的标签；`上新`/`套餐`/`爆款` 这类运营标记一律跳过，
   否则会出现「上新。这批里有它。」这种把后台字段当文案的事故。
2. 名称意象（`巨无霸`→"经典"、`厚`→"厚实"、`脆`→"咔嚓一声"、`薯`→"薯条的香"）
3. 系列氛围词（BU→"扎实的牛肉"、CH→"咔嚓一声"、CF→"咖啡因到位"）——**仅主食位可用**
4. 品类兜底（小食→"配着正好"、饮料→"先喝一口"、甜品→"甜的收尾"）

> 端盒里的小食/饮料**不得**走第 3 级：一杯清水被写成"咔嚓一声"是明显的系统错位。

### 4.3 各等级语气模板

| 等级 | 模板 | 示例（对应真实商品） |
|---|---|---|
| N | `{风味}。{日常落点}。` | 麦香鱼 → 「鳕鱼的软。今天想吃点温柔的。」 |
| R | `{风味}。{肯定落点}。` | 板烧鸡腿堡 → 「板烧滋滋。这一口，稳的。」 |
| SR | `{风味}。{稀缺落点}。` | 龙焰鸡腿堡 → 「韩式辣椒黄油风味。赶上了，就是你的。」 |
| SSR | `{图腾意象}。{史诗落点}。` | 巨无霸 → 「两层牛肉，一个宇宙。传说就该这样出场。」 |

### 4.4 禁忌词（生成时硬过滤）

| 类别 | 禁用词 | 原因 |
|---|---|---|
| 健康功效 | 养生、排毒、低卡减肥、吃了不胖、更健康 | 不得作营养/健康声称 |
| 绝对化 | 最好吃、第一、天花板、永远的神、零差评 | 广告法绝对化用语 |
| 品牌关系 | 官方、联名、限量发售、正版授权、典藏 | 暗示官方背书 |
| 诱导消费 | 必买、不买亏了、最后一天、手慢无、错过再等一年 | 赛事规则禁止诱导/稀缺胁迫 |
| 攀比 | 欧皇、非酋、氪金、抽不到就是穷 | 赌博化表达，且伤害用户 |
| 对比 | 比 XX 好吃、吊打、碾压 | 规则禁止与其他品牌对比 |

> 实现：`references/copywriting.md` 里维护一个 `FORBIDDEN` 数组，`draw.py` 生成后 grep 一遍，命中就回落到安全模板「{风味}。今天也不错。」。

## 5. 视觉规范（卡面）

### 5.1 版面（600×840，2:2.8）

```
┌──────────────────────────┐
│ 系列名 / season        SSR│  ← 顶部：系列标识 + 稀有度徽章
│                          │
│    ┌────────────────┐    │
│    │                │    │  ← 官方商品图（白底衬托，圆角 24）
│    │   商品主图      │    │     尺寸 420×420，居中
│    │                │    │
│    └────────────────┘    │
│                          │
│  龙焰鸡腿堡三件套          │  ← 商品名：32px 粗体，>8 字自动缩到 26px
│  韩式辣椒黄油风味。        │  ← flavorText：18px，行高 1.6
│  赶上了，就是你的。        │
│                          │
│  能量 485kcal  ▮▮▮▯▯    │  ← 属性区：kcal 为主，四维条形
│  蛋白 24g 脂肪 24g 碳水 42g│
│                          │
│  CH-07/14        ¥26.90  │  ← 编号 + 现价（价格必须显示）
│  非官方产品 · 参赛作品      │  ← 强制水印，16px，40% 不透明
└──────────────────────────┘
```

### 5.2 稀有度视觉差异（必须一眼可辨）

| 等级 | 边框 | 特效 | 揭晓动效时长 |
|---|---|---|---|
| N | 1px `rgba(255,255,255,.18)` | 无 | 0.6s 淡入 |
| R | 2px 银色渐变 | 顶部一道高光 | 0.9s |
| SR | 3px 金色渐变 | 斜向流光循环 1 次 | 1.4s |
| SSR | 4px 虹彩渐变 | 12 个粒子 + 全卡泛光 | 2.2s + 0.6s 停顿 |

> 动效在终端/聊天里退化为**文字节奏**：SSR 揭晓前多一行占位（"……"），用"停顿"代替"粒子"。这是 chat-first 产品的正确做法，不要试图在文本里做动画。

### 5.3 禁止事项

- ❌ 不使用麦当劳 Logo、金拱门图形、"i'm lovin' it" 字样作为设计元素
- ❌ 不使用任何从官网/电商截取的包装设计稿、KV、海报
- ❌ 不使用未授权商用字体文件（用系统字体栈：`PingFang SC, Noto Sans SC, sans-serif`）
- ✅ 只使用 `query-meals` 返回的商品图 URL（这是 MCP 官方数据的一部分）

### 5.4 端盒卡（另一种版式，600×840）

端盒是"抽完就是一顿饭"，不能拆成三张小卡拼贴——那又把选择还给了用户。版面：

```
┌──────────────────────────┐
│ 脆鸡江湖 · 端盒      20261024-CH-B01│
│ 主食+小食+饮料｜咔嚓声，是开箱的预告  │
│  ┌──────────────────────┐│
│  │     主食大图（官方）    ││  286 高，白底衬托
│  └──────────────────────┘│
│  主食 · 常驻              │
│  麦香鸡            ¥17   │
│  ┌──┬─────────────┬────┐ │
│  │图│小食·常驻 那么大鸡排│¥14│ │  两行小队，各 108 高
│  ├──┼─────────────┼────┤ │
│  │图│饮料·常驻   纯悦  │¥7.5│ │
│  └──┴─────────────┴────┘ │
│  整盒合计                 │
│  ¥38.5      369 kcal（2/3 项有官方数据）│
│              共 3 件 · 单品现价累加      │
│  非官方产品 · 参赛作品 · 组合价以下单页为准│
└──────────────────────────┘
```

**硬规则**

- 总价**永远**是单品现价累加；省 0 元时不要写"省 ¥0"，改写"共 N 件 · 单品现价累加"。
- 总热量只累加**有官方营养数据**的项，并注明覆盖 `2/3`；一项都没有时写"官方表未覆盖，不估算"。
- 结构降级（只凑到 2 件或 1 件）时，`structure` 字段如实写，卡片不假装是三件。
- 卡面不出现任何"套餐价/立减/优惠组合"字样——那是官方的事，本项目只做加法。

## 6. 人格卡（FR-11）

基于收集册的品类分布，输出一张"麦门 DNA"卡。

### 6.1 分桶

| 桶 | 命中条件 |
|---|---|
| `beef` 牛肉派 | 商品名含 牛肉/牛堡/巨无霸/安格斯/吉士 |
| `fried` 脆皮依赖 | 含 炸鸡/鸡翅/麦乐鸡/鸡排/脆汁鸡/V翅 |
| `sweet` 甜品续命 | 冰淇淋/麦旋风/新地/派/圆筒/阿芙佳朵 |
| `coffee` 咖啡因驱动 | 麦咖啡/奶铁/美式/拿铁/卡布 |
| `light` 轻食自律 | 沙拉/玉米杯/苹果片/纯悦/无糖/500大卡 |
| `share` 社交型 | 拼盘/多人餐/分享/双人/派对 |

### 6.2 输出模板

```
你的麦门 DNA：{主桶标签}（{占比}%）
副属性：{次桶标签}（{占比}%）

一句话人格：{人格句}

样本：{总抽数} 抽 · {系列数} 个系列 · 首次 {firstDate}
```

主桶人格句示例（每桶 3 句，按抽数奇偶轮换，避免每次一样）：

- 牛肉派：「你和巨无霸的关系，比和同事还稳定。」
- 脆皮依赖：「咔嚓声是你的开机音效。」
- 甜品续命：「甜味不是奖励，是基础设施。」
- 咖啡因驱动：「你的血液里有一条麦咖啡管线。」
- 轻食自律：「你在自律和薯条之间，保持了体面的平衡。」
- 社交型：「一个人吃叫吃饭，两个人吃才叫麦门。」

> 人格卡**不排名、不比较**（不做"你超过了 98% 的用户"），避免攀比与赌博化表达。

## 7. 拆盒播报模板（对话输出，4 段式）

```
① 洗牌（1 句，制造仪式感，≤20 字）
   例：「正在摇匀本店 132 个可能…」

② 揭晓（根据稀有度决定节奏，≤15 字）
   N/R ：「开。」
   SR   ：「这个…有点东西。」
   SSR  ：先一行「……」再「等等，这张不一样。」

③ 卡面（结构化输出，见 SPEC §3.3）
   商品名 · 价格 · 编号 · 稀有度 · flavorText · 属性
   附：官方商品图（Markdown 图片）

④ 结论 + 下一步（1 句，必须给结论，不给选项列表）
   例：「就它了。¥26.9，比单点省 20.6。要下单吗？」
```

**反面示例（禁止）**：
> 「为您推荐以下几款：1. 巨无霸 2. 麦辣鸡腿堡 3. 板烧…请问您需要哪一个？」

这等于把决策成本又还给用户，产品价值归零。
